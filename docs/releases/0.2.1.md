# rotom 0.2.1：发布冻结与说明

状态：维护者已明确授权 `@bingjiang0611/rotom@0.2.1` / `latest`。尚未发布；以下不是最终 tgz 的验收结果。

## 变化

- 已有受管 macOS helper 随 `rotom update` 自动同步；npm 更新则在下一次正常启动 rotom 时同步。不再要求额外的 `rotom helper update`、停止确认或签名变量。
- 复用已安装 helper 的签名 Authority 对应的唯一有效身份；先准备、签名并验签候选，成功后才关闭旧 helper。当前 native 摘要和 Info.plist 不变时不重签、不停止。
- 共享 helper 更新会断开其他会话的 Computer Use 连接；下次使用启动新 helper。未知 shutdown/替换保留锁，禁止自动重放；不强杀、不自动回滚，不静默降低证书签名到 ad-hoc。
- 版本/帮助/模型列表/包管理查询不升级 helper；自定义 app 路径仍由调用方管理。RPC stdout 保持 JSON，升级日志走 stderr。
- 组件为 `0.5.1-rotom.5`，原生预构建字节与 0.2.0 的 `.rotom.4` 相同；Pi fork、helper 协议 11 与 broker 协议 2 均未变化。

系统权限和签名身份不可用时仍须明确报错，不能绕过系统策略。完整原生自动停启在本轮源码验收中尚未通过，最终产物须单独补验；L2、pid 投递与 B1–B6 等既有边界不因本版本扩大。源码检查及失败证据见 [自动同步记录](../agent/computer-use-v2/STATUS-8-auto-upgrade.md)。
