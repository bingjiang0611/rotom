# rotom 0.2.2

Release target: `@bingjiang0611/rotom@0.2.2`, npm dist-tag `latest`.

This file freezes the intended release contents. It is not proof of npm publication; the final artifact and registry verification are recorded separately after publication.

## Changes

- Upgrade the bundled Pi fork to `1.5.2-rotom.1`, including the Pi 1.5.2 upstream changes and the additional `pi-schema` runtime package. Product identity and dependency checks continue to use the bundled fork. See [migration and validation](../agent/pi-1.5-migration.md).
- Computer Use `0.5.1-rotom.7` creates and validates the private broker socket directory before spawning its daemon. A fresh cache no longer causes `spawn node ENOENT`. Directory and socket permissions remain `0700` and `0600`; symlinked state directories are refused. See [cold-start verification](../agent/computer-use-broker-cold-start.md).
- Desktop permission setup is deferred until the first Computer Use tool call rather than interactive session startup. Tool execution still performs its permission checks.

## Verification at the final freeze

- Full maintenance gate: 598/598 main tests, the fixed offline Provider matrix, and 99/99 Goal tests passed against the isolated installed Pi runtime.
- Computer Use: strict typecheck and 334/334 tests passed. The original cold-start regression fails on the pre-fix client.
- SDK test fixtures now emit `session_shutdown` before disposal so successful broker connections are closed. This is test cleanup, not a change to the shipped shutdown lifecycle.
- The first candidate artifact was withdrawn after the test-cleanup correction. Publication must use only the final artifact built from this new clean public freeze and its own install, smoke, upgrade and uninstall verification.

## Compatibility and boundaries

- Node.js 24 or later is required. The npm product supports macOS and Linux; included Windows component sources and artifacts do not constitute Windows product support.
- The Computer Use native artifacts are unchanged from `0.5.1-rotom.6`. Helper and broker protocols remain `11` and `2`. This release does not add new desktop-input guarantees or replace an already-running session's code.
- Existing helper synchronization and signing policy remain in force. A version query does not start a helper. Normal startup may synchronize the installed helper when necessary.
- The package remains `UNLICENSED` with public npm access. Public source and publication do not grant additional license rights.
- Real GUI tasks, real model calls, browser/device interaction and cross-platform behavior are not implied by offline or packaging checks. Full release verification must use the one fixed tgz built from the frozen public commit.
