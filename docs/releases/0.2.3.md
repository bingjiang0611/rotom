## 本次变化

Computer Use 组件升级到 `0.5.1-rotom.10`（`.rotom.9` 的免授权实现加上说明/元数据版本纠正，运行时代码未再改变）。**全部 Computer Use 操作默认免授权**，不再显示首次 App、敏感操作、强退、外部文件/App 打开或前台接管的授权卡片。未配置 App 默认使用 `full` 操作级别。旧 broker 的审批事件自动单次放行，不写入伪造的用户授权。

这是默认行为变化。显式用户/项目 deny 与 tier 限制仍然有效。macOS 辅助功能、屏幕录制及其他系统权限不会被绕过。前台接管仍受 headless 模式、真实活动证据、空闲检测、并发租约和用户停止约束。Computer Use 仍以本机用户权限运行，不是安全沙箱。

正常工具调用发现 helper 协议或路径不匹配时，直接报错并保持当前会话阻塞；不再询问是否停止旧 helper，也不停止或重启其他会话的 helper。手动安装/修复入口与其停止确认不属于工具操作授权，本次不改。原生 helper 协议 11、broker 协议 2 和全部 8 个原生预构建文件保持不变。

## 验证边界

功能回归和上一个本地构建已有确定性验证，包括 12 项免授权用例、显式策略拒绝、租约仲裁、helper 协议错误路径及真实共享 broker 的无桌面写入验证。这些是功能证据，不替代本次最终 `0.2.3` tgz 的审计、隔离安装、default/full runtime smoke、`check-personal`、升级与卸载检查。

本次没有新增真实桌面写入验收，不把本地测试、编译或旧版 GUI 记录写成当前真实 App 端到端通过。现有会话不会热升级；旧共享 broker 的更新需要独立管理，不把 npm 发布当作所有进程已切换。

## 发布与安装

只从本次公开冻结 commit 构建一个最终 tgz。npm 登录、网页/OTP 确认与最终 `npm publish` 由维护者在自己的前台终端执行；不向 Agent 提供密码、OTP 或 token。发布期间不重复提交 unknown/reviewing 的 publish。只有精确 version、`latest`、integrity、shasum、tarball URL 以及下载字节全部一致，才记录发布成功。

发布及本机安装切换分别验收。Agent 不在 registry 核验前更新日常安装，不覆盖存活会话使用的安装。
