# 压缩摘要更新与工具描述精简验证

本次只处理摘要更新和 Subagent 描述；不调整重试、等待工具、个人设置或发布版本。

## 实现与兼容性

- Pi 的更新摘要提示从“保留全部旧信息”改为重写当前状态，合并已完成工作，保留当前目标、约束、未完成工作、错误和仍有效的决策。长度要求是软目标：新工作需要时可以增长；不降低 `maxTokens`，不放宽未完成摘要的拒绝条件。
- 仅识别 Pi 默认压缩中与 `details` 完全一致的末尾文件清单。内置压缩不把该后缀重新送给模型，也不在没有新历史时重复复用后再追加。文件信息仍通过 `fileOps` 合并、保存在 `details` 和最终摘要中。
- 扩展收到的 `preparation.previousSummary` 保持完整。新增可选 `previousSummaryFileListSuffix` 只供内置压缩使用；hook 摘要、缺失元数据和不匹配后缀不裁剪。提示词不统一禁止文件清单，避免误删 hook 自行维护且 Pi 不会携带的清单。旧持久化记录不改写。
- Subagent 只在现有产品投影 `constrainSubagentParameters()` 中缩短 8 个参数描述。不删字段，不改变校验、默认值、作用域、权限或原始 SDK 输入。无需修改组件原始来源清单或重新打包组件。

## 真实模型重放
