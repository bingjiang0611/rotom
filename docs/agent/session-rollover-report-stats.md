**门槛结论：不达标。** 门槛是“越线会话中至少一半能在首次原生压缩前被轮间轮转接管”，2× 只有 26.6%（30/113），3×、4× 也只有 41.6%、48.7%。按设计 9.1，B 不合入 `main`：保持默认关闭的 opt-in，不改门槛，也不改选 3×/4×（那是设计变更，需要用户决定）。

分类修正后的关键事实：329 个越线段里 316 个发生在轮中（96.0%）。Pi 在同一轮的**下一次请求前**就会压缩，所以越线几乎总是先被轮内压缩吃掉；轮间点本来就少，能提前越线的更少。
