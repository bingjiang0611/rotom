## 先修正评测器冲突

初始 runner 只通过用户任务和 README 声明临时工作区、命令限制与 JSON-only 输出。产品系统提示却要求 Git 预检和结构化人工报告。由此出现重复尝试被禁命令、正文/Markdown 围栏破坏 JSON 解析，以及耗尽模型 turn。最初的分数差异混有协议遵从差异，不能全部归因于任务行为。

修正：两组都在 `before_agent_start` 追加同一调用方系统合同，明确非 Git 工作区、工具边界和输出协议。它不包含隐藏答案。原工具门禁、文件检查、judge、JSON 解析、重复数与时间/turn 上限均未放宽。新增 faux provider 集成检查，在真正的标准化模型请求中验证产品提示仍存在，调用方合同按开/关控制出现且位于最后；这不是付费模型结果。

仍有模型偶发忽略协议，最终批次 candidate 的一个失败就是 Markdown 围栏。该样本仍记失败，没有修补答案或静默算通过。修正前后批次不合并计算提示收益。

## 用量、耗时与异常

所有轮次合计：

- 200 个样本，170 个评分通过、20 个评分失败、10 个无可评分终态。
- 10 个未完成中：9 个由 suite 的 turn 上限中止，1 个为 provider 工具参数错误。turn 上限中止是有界任务未完成，不冒充网络故障，也不写成成功。
- 记录到 **14,478,577 tokens**（包括缓存读取）、2,055 条 assistant 消息；测试样本耗时累计约 **89.1 分钟**，不含准备和人工分析时间。
- 已知 billable credits 小计 **28.214176 Cr**，另有 **1 条 unknown**。这是已报告的小计，不是完整账单；USD 未知。没有使用余额差推算或把 Pi 的 $0 当实际费用。

|---|---:|---:|
